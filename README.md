## Stack

- [TanStack Start](https://tanstack.com/start) (React + Vite)
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui components

## Run locally

```bash
bun install
bun dev
```

Build:

```bash
bun run build
bun run preview
```

## Structure

```
src/
  components/ui/     # UI components (including ContainerScroll)
  routes/            # File-based routes
  lib/               # Utilities
  styles.css         # Global styles + theme
```
